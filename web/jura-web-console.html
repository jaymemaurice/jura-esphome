Every displayed value is one byte. Two-byte EEPROM words remain individually selectable; matching backgrounds and outer borders group known logical fields and the ten eight-byte recipe/action records. Click a hex byte or its ASCII character to select both.

Product values
Decoded directly from EEPROM recipe/action bytes, with current physical-button light/flash state from RAM 0xD6/0xD7. Send buttons use physical FA slots (not product function codes) and unlock only after a complete live EEPROM capture from this device; sending a product command may start dispensing.


Decoded product / function codes
Informational function map from our controlled slot-remapping sweep. “Currently assigned” is read from the ten EEPROM recipe/action records above, so remapped Ristretto, Pot, Grinder Selector, hold-actions, etc. are immediately visible. A function code is NOT an FA command: each Send button follows the slot's actual FA mapping. Read EEPROM live first to enable these buttons. Locked and unsafe functions cannot be sent from table buttons.
